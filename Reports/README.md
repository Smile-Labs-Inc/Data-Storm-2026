# Reports

| File | Purpose |
|---|---|
| `final_report.md` | 5-page PDF source (markdown). Sections: cover, forensics, POI, methodology, GenAI log + validation. |
| `build_pdf.py` | one-shot pandoc build (`python build_pdf.py`). Requires pandoc + xelatex on PATH. |
| `final_report.pdf` | generated; gitignored. The actual deliverable. |
| `figures/` | DAG, sensitivity table, etc. -- gitignored, regenerated by `run_pipeline.py`. |

## Quick build

```powershell
cd Reports
python build_pdf.py
```

If pandoc is unavailable, paste `final_report.md` into any Markdown -> PDF tool (VS Code Markdown PDF extension, pandoc.org online, Typora, etc.).

## Before submitting

1. Replace `[Team Name]` and `[Submission Date]` placeholders in `final_report.md`.
2. Re-run `python build_pdf.py`.
3. Confirm the PDF is exactly 5 pages (incl. cover) -- pandoc + the geometry settings should yield this; tighten margins/font if it overflows.
4. Visually inspect the DAG (page 3) and the validation table (page 5) render correctly.
5. Ship.
